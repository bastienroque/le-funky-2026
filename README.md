# Le Funky — Portfolio Website

A sleek, responsive digital portfolio for **Le Funky**, a tattoo and graffiti artist. Built with Next.js, Tailwind CSS, Lucide Icons and Shadcn primitives.

---

## 🎨 Overview

This website serves as a visual showcase for Le Funky's creative works spanning graffiti murals and tattoo art. It features an adaptive masonry gallery layout, responsive image lightboxes with touch gestures, and seamless mobile navigation.

- **Art Focus:** Graffiti & Tattoo Portfolio
- **Architecture:** Static / Client-rendered Next.js application (Frontend-only)
- **Design Strategy:** Minimalist, high-contrast dark aesthetic built around media presentation

---

## ✨ Features

- **Masonry Artwork Grid:** Dynamic column layout that preserves intrinsic aspect ratios across portrait, landscape, and square artworks without forced cropping.
- **Touch-Enabled Lightbox:** Full-screen modal with keyboard navigation (arrow keys), mobile swipe gestures, and responsive side/bottom controls.
- **Adaptive Mobile Layouts:** Fluid mobile navigation drawer and automatic drawer closure upon route changes.
- **Optimized Image Loading:** Uses `next/image` with responsive blur/fill sizes and priority loading for fast asset delivery.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, TypeScript)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
